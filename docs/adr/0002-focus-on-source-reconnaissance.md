# Focus grok-search-cli on realtime source reconnaissance

grok-search-cli is a Grok long-board amplifier rather than a generic replacement for Codex Web Search, Exa, Tavily, or browser access. Its primary job is to produce high-recall realtime Source Packs from Grok's strengths on X, community, and edge sources, with Temporal Evidence Weighting and an auditable Evidence Contract guiding later verification.

The CLI keeps Tavily and Firecrawl only for old Grok Search MCP feature parity in explicit `fetch`, `map`, and `--extra-sources` paths. It does not become a smart-search router.
